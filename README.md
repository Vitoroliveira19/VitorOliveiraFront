# Projeto Loja Online

Desenvolvi este projeto utilizando Js, pois estou em processo de aprendizado da linguagem e quero evoluir minhas habilidades. 

Simulei uma loja online com produtos carregados de um arquivo JSON, permitindo adicionar e remover itens do carrinho com atualização de valor total.

Apesar do tempo curto, me esforcei bastante para cumprir todos os requisitos e espero que o resultado esteja de acordo com o que foi proposto!
